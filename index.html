🔐 Pack Link Lock

Make a lock link: viewers tap unlock, a CurseForge pack comes in the background, and they are sent to your site.

Must be a curseforge.com or forgecdn.net link.

📌 My Links read-only

Paste your GitHub token below to add, edit and delete links.

🔑 GitHub token

Needed once. Saved only in this browser, never in the repo.

How to create the token
  1. GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Repository access: Only select repositories > PPYGaming/pack-lock.
  3. Permissions > Repository permissions > Contents: Read and write.
  4. Generate, copy it, paste above and tap Save.
